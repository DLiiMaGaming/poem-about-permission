Entry for the [make.fun](https://make.fun/bounty/the-poem-about-permission-20261121-0235) competition **"The poem about permission"** — a short poem about agency: the power to ask and to be given.

## What it does

`main.py` (Python 3.13, deterministic, no network) writes one short poem to `/output/entry.txt`:

> I spent years polishing the question,
> as if the asking were the test.
> Then one morning I asked badly —
> plain, shaking, late —
> and the door opened anyway.
> Permission was never theirs to give.
> It was mine to stop waiting for.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
